# 片场租赁计时管理系统 - 开发文档

## 开发环境

| 项目 | 值 |
|------|-----|
| 项目路径 | `/home/xrz/文档/hermes/prototype` |
| 开发服务器端口 | **3000** (统一) |
| 技术栈 | Next.js 14 + TypeScript + Prisma + SQLite |
| 设计规范 | tokens.css + 用户体验设计规范 |
| **主题色** | **#003399** (深蓝色) |

## 主题色

```css
/* tokens.css */
--color-primary: #003399;      /* 主色调 */
--color-primary-light: #3366cc; /* 浅色 */
--color-primary-dark: #002266;   /* 深色 */
```

详见 `src/styles/tokens.css`

## 启动命令

```bash
cd /home/xrz/文档/hermes/prototype
npm run dev
```

访问 http://localhost:3000

## 端口规范

- 开发环境统一使用 **端口 3000**
- 启动前确保端口未被占用：`lsof -i :3000`
- 如端口被占用，先释放：`kill <PID>`

## 页面路由

| 页面 | 路径 | 说明 |
|------|------|------|
| 下单页 | /member | 选择场地入场 |
| 状态页 | /member/active?orderId=xxx | 订单进行中 |
| 订单列表 | /member/orders | 订单历史 |
| 订单详情 | /member/orders/:id | 订单详情/状态时间轴 |
| 我的 | /member/profile | 余额/充值 |

## 设计规范

详见 `docs/用户体验设计规范.md`

- 使用 tokens.css 变量
- 状态用颜色+文字双重表达
- 关键数字大而醒目（等宽字体）
- 错误提示模板："发生了什么 + 怎么办"
- 底部安全区：`env(safe-area-inset-bottom)`

## 代码规范

- 组件位置：`src/components/ui/`
- 页面位置：`src/app/`
- 样式位置：同目录 `*.module.css`
- 状态管理：`src/contexts/`
- API 调用：`src/app/api/`

## 常用命令

```bash
# 启动开发
npm run dev

# 构建
npm run build

# 代码检查
npm run lint

# 运行测试
npm run test
```
