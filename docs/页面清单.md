# 页面清单

> 本文档列出所有前端页面，包含页面目标、关键信息、主要操作、异常态、跳转关系
>
> **设计规范引用**：本文档遵循 `用户体验设计规范.md` 中的所有设计原则

---

## 设计规范摘要

### 信息优先级

| 端 | 优先级 |
|----|--------|
| **用户端** | 1. 当前状态 → 2. 时间/金额 → 3. 余额 → 4. 下一步行动 |
| **管理员端** | 1. 待审核数量 → 2. 订单概要 → 3. 资产清点 → 4. 调价入口 → 5. 操作按钮 |

### 统一规范

| 类型 | 标准 |
|------|------|
| 按钮 | 主按钮(.btn-primary)、次按钮(.btn-secondary)、危险按钮(.btn-danger) |
| 反馈 | 加载中、成功、失败、空状态 四种状态 |
| 文案 | 入场/离场/确认扣款/放行（统一用词） |
| 时间格式 | `YYYY-MM-DD HH:mm` |
| 金额格式 | `¥0.00`（等宽数字 font-variant-numeric: tabular-nums） |
| 错误提示 | `{发生了什么}，{怎么办}` |
| 状态表达 | 颜色 + 文字 双重表达 |
| 危险操作 | 二次确认（扣款、放行） |

### 导航结构

#### 全局导航

| 端 | 导航形式 |
|----|----------|
| **用户端** | 底部标签栏（首页、订单、我的）+ 底栏固定操作栏 |
| **管理员端** | 顶部固定导航栏 + 侧边栏菜单 |

#### 用户端底部结构

```
┌─────────────────────────────┐
│        顶部区域              │
│     （会员信息/余额等）       │
├─────────────────────────────┤
│   底栏固定操作栏（可选）      │
│  ┌─────────────┬─────────┐ │
│  │  估计价格    │ 下单按钮 │ │
│  └─────────────┴─────────┘ │
├─────────────────────────────┤
│  [首页]    [订单]    [我的] │
└─────────────────────────────┘
```

- **顶部区域**：页面主要内容，如会员信息、余额等
- **底栏固定操作栏**（可选）：位于底部标签栏上方，用于展示关键信息和主要操作按钮
  - 未登录时：价格为空，按钮显示"请登录"
  - 已登录时：显示估计价格，按钮显示"下单"
  - 高度约 56px，固定定位
- **底部标签栏**：固定定位，包含首页、订单、我的 三个标签
  - **首页**：始终跳转到首页
  - **订单**：跳转订单列表页
  - **我的**：已登录时跳转到账户设置页，未登录时跳转到登录页

#### 管理员端顶部导航栏

```
[片场管理] [场地] [设备] [会员] [订单] [审核] [日志] ... | [通知] [用户名] [登出]
```

- 左侧：功能模块入口
- 右侧：通知入口、当前管理员名、登出按钮

#### 面包屑规范

面包屑显示路径：`首页 > 会员管理 > 会员详情`

| 场景 | 面包屑示例 |
|------|-----------|
| 一级页面 | `首页` |
| 二级页面 | `首页 > 订单管理` |
| 三级页面 | `首页 > 订单管理 > 订单详情` |

- 面包屑首项始终为"首页"（可点击返回）
- 当前页面不设链接（disabled）
- 分隔符使用 ` > `

### 页面层级

| 级别 | 定义 | 示例 | 标题层级 |
|------|------|------|----------|
| 一级 | 独立页面 | 登录页、首页 | h1 |
| 二级 | 列表/详情页 | 订单列表、订单详情 | h2 |
| 三级 | 弹窗/抽屉 | 充值抽屉、申请离场弹窗 | h3 |

### 页面浮现方式

| 方式 | 定义 | 适用场景 | 动画 |
|------|------|----------|------|
| **跳转** | 完整页面切换 | 首页、订单列表、订单详情等列表/详情页 | 页面整体切换 |
| **滑入** | 从右侧滑入新页面 | 登录页、注册页、SKU选择页 | 从右向左滑入，关闭时向左滑出 |
| **弹窗** | 模态遮罩居中展示 | 确认类操作、二次确认 | 渐显 + 缩放 |
| **抽屉** | 从底部滑入 | 充值、筛选等表单类操作 | 从底部向上滑入 |

- **滑入页面特点**：作为独立页面存在，但通过滑入动画呈现，不影响 URL
- **返回机制**：滑入页面左上角显示返回按钮，点击后滑出关闭

### 技术实现说明

#### 页面间数据传递

| 场景 | 方式 |
|------|------|
| 列表→详情 | URL路径参数 `/order/:id` |
| 表单提交后跳转 | URL查询参数 `?from=sku` |
| 登录态 | localStorage 存储 token |
| 订单状态 | URL直接访问 `/order/:id` |

#### 状态更新机制

| 场景 | 机制 |
|------|------|
| 入场成功页计时器 | 客户端 setInterval，每秒更新显示 |
| 订单状态轮询 | 页面内 setInterval，每5秒轮询订单状态 |
| WebSocket | MVP 范围外，暂不实现 |

#### 移动端适配

- 视口：`viewport-fit=cover`
- 触摸目标：最小 44×44px
- 底部安全区：`env(safe-area-inset-bottom)`
- 响应式断点：
  - 手机：< 768px（单列布局）
  - 平板：768px - 1024px（双列布局）
  - 桌面：> 1024px（多列布局）

#### 标题层级

| 页面元素 | HTML标签 | 样式 |
|----------|----------|------|
| 页面大标题 | `<h1>` | font-size: 24px, font-weight: 600 |
| 区块标题 | `<h2>` | font-size: 18px, font-weight: 600 |
| 卡片标题 | `<h3>` | font-size: 16px, font-weight: 500 |
| 正文 | `<p>` | font-size: 14px, font-weight: 400 |

### 1.1 登录页

| 项目 | 内容 |
|------|------|
| **页面目标** | 用户通过假授权方式登录系统 |
| **信息优先级** | 无（首入口） |

| **附加信息** | - "此为演示系统，无需注册可直接登录" |
| **跳转关系** | 成功 → 首页<br/>未注册 → 注册页 |
| **页面浮现方式** | 从右侧滑入 |

### 1.3 首页（会员中心）

| 项目 | 内容 |
|------|------|
| **页面目标** | 展示余额、SKU选择器、快速下单入口 |
| **信息优先级** | 1. 余额卡片 → 2. SKU选择器 → 3. 底栏固定操作栏 → 4. 底栏导航 |
| **页面结构** | 页面从上到下：余额卡片 → SKU选择器 → 底栏固定操作栏 → 底部标签栏 |
| **余额卡片** | 显示余额（¥0.00格式，大字），点击跳转充值抽屉；余额为0时显示"请先充值"提示 |
| **SKU选择器组件** | 以卡片网格形式展示租赁项目：<br/>- **场地选择**：3列网格，每行3个选项，每张卡片显示场地名称、价格，单选<br/>- **设备选择**：2列网格，每行2个选项，每张卡片显示设备名称、价格、数量控制器（− 0 +），可多选<br/>- **动态计价**：根据已选场地和设备实时显示预计价格（默认5小时） |
| **底栏固定操作栏** | 位于底部标签栏上方，高度约 56px，包含：<br/>- **信息展示**：当前选择的估计价格（未选择场地时显示"请选择场地"）<br/>- **操作按钮**：未登录时显示"请登录"，已登录时显示"下单"(.btn-primary) |
| **底栏导航** | 底部标签栏（首页、订单、我的），固定定位 |
| **主要操作** | 1. 点击余额卡片跳转充值抽屉<br/>2. 在SKU选择器中选择场地（3列网格）和设备（2列网格）<br/>3. 查看实时估计价格<br/>4. 点击"下单"直接入场（创建订单+自动入场+开始计时）<br/>5. 点击"请登录"进入登录页（未登录）<br/>6. 有进行中订单时点击"租赁"导航跳转到状态页<br/>7. 点击底栏"订单"跳转订单列表页<br/>8. 点击底栏"我的"跳转账户设置页或登录页（未登录） |
| **动态计价规则** | - 场地单价 × 默认时长 + 设备单价 × 数量 × 默认时长<br/>- 默认时长：5小时<br/>- 选择场地后开始计价，未选场地时显示"请选择场地" |
| **异常态** | - 余额为0且已登录：**"请先充值"**，价格展示区显示提示，"下单"按钮置灰(.btn-primary:disabled)<br/>- 未选择场地：**"请选择场地"**，下单按钮置灰 |
| **跳转关系** | 余额卡片 → 充值抽屉<br/>下单 → 状态页（入场+开始计时）<br/>请登录 → 登录页<br/>继续使用 → 状态页<br/>底栏"租赁"（有进行中订单）→ 状态页<br/>底栏"订单" → 订单列表页<br/>底栏"我的"（已登录）→ 账户设置页<br/>底栏"我的"（未登录）→ 登录页 |
