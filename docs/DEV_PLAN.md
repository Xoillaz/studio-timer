## 开发规范

### 状态管理
- 用户端：React Context + localStorage
- 管理员端：React Context + sessionStorage

### API 调用
- 使用 `fetch` 或 `axios`
- 统一错误处理：`{ code, message, details }`
- 认证：`Authorization: Bearer <token>`

### 组件开发
- 先写测试（Vitest）
- 遵循 tokens.css 变量规范
- 移动端优先

### TDD 流程
1. 写测试用例（RED）
2. 写实现代码（GREEN）
3. 重构（REFACTOR）
