# 角色与权限矩阵

## 角色定义

| 角色 | 说明 | 场景 |
|------|------|------|
| 会员用户 | 剧组负责人（制片/外联/场务） | 通过Web端操作 |
| 管理员 | 片场现场人员 | 通过Web端操作 |

---

## 权限矩阵

### 会员用户

| 权限项 | 权限码 | 说明 |
|--------|--------|------|
| 登录/授权 | `user.login` | 假授权弹窗登录，localStorage存储 |
| 查看个人信息 | `user.profile` | 查看自己的会员信息 |
| 充值 | `user.recharge` | 模拟充值，添加虚拟余额 |
| 查看余额 | `user.balance` | 查看当前余额 |
| 扫码入场 | `order.entry` | 选择场地设备，扫码开门入场 |
| 申请部分人离场 | `order.partial_exit` | 输入离场人数+备注，通知管理员 |
| 申请离场 | `order.exit` | 扫码申请离场，触发计费 |
| 补差价 | `order.topup` | 余额不足时充值差价 |
| 查看自己的订单 | `order.list` | 查看入场记录和账单 |
| 查看自己的日志 | `log.list` | 查看自己的操作日志 |

### 管理员

| 权限项 | 权限码 | 说明 |
|--------|--------|------|
| 登录 | `admin.login` | 管理员登录 |
| 场地管理 | `venue.manage` | 增删改查场地 |
| 设备管理 | `equipment.manage` | 增删改查设备 |
| 会员管理 | `member.manage` | 查看所有会员，查看余额 |
| 订单管理 | `order.manage` | 查看所有订单 |
| 审核部分人离场 | `order.approve_partial_exit` | 审核并手动放行部分人 |
| 审核账单 | `order.approve` | 审核账单，添加额外费用，确认扣款 |
| 手动放行 | `order.release` | 确认扣款后手动开门放行 |
| 查看所有日志 | `log.manage` | 查看所有操作日志 |
| 收到通知 | `notify.receive` | 接收关键事件通知（入场、离场、补差价等） |

## 订单状态流转

```
pending_entry（待入场）→ entering（入场中）→ partial_exit_pending（部分人离场待审核）→ entering（入场中）
                                              → pending_exit（离场申请）→ reviewing（审核中）→ completed（已完成）
                                                        ↘ topup_pending（补差价待审核）→ reviewing（审核中）
                                                         ↘ rejected（已拒单）→ entering（入场中）
```

**状态说明：**

| 状态码 | 说明 |
|--------|------|
| `pending_entry` | 待入场（选择了场地设备，未扫码） |
| `entering` | 入场中 |
| `partial_exit_pending` | 部分人离场待审核 |
| `pending_exit` | 离场申请（已申请，等待审核） |
| `topup_pending` | 补差价待审核 |
| `reviewing` | 审核中（账单待管理员审核） |
| `rejected` | 已拒单 |
| `completed` | 已完成 |

## 日志类型与权限

| 日志类型 | 日志码 | 产生者 | 查看权限 |
|----------|--------|--------|----------|
| 扫码入场 | `entry` | 会员用户 | 会员用户、管理员 |
| 申请部分人离场 | `partial_exit_apply` | 会员用户 | 管理员 |
| 审核部分人离场（通过） | `partial_exit_approve` | 管理员 | 会员用户、管理员 |
| 审核部分人离场（拒绝） | `partial_exit_reject` | 管理员 | 会员用户、管理员 |
| 申请离场 | `exit_apply` | 会员用户 | 管理员 |
| 申请补差价 | `topup_apply` | 会员用户 | 管理员 |
| 审核补差价（通过） | `topup_approve` | 管理员 | 会员用户、管理员 |
| 审核补差价（拒绝） | `topup_reject` | 管理员 | 会员用户、管理员 |
| 账单审核（通过） | `bill_approve` | 管理员 | 会员用户、管理员 |
| 账单审核（拒绝/拒单） | `bill_reject` | 管理员 | 会员用户、管理员 |
| 已扣款 | `paid` | 系统 | 会员用户、管理员 |
| 已放行 | `released` | 管理员 | 会员用户、管理员 |
