# Studio Timer - 片场租赁计时管理系统

片场租赁计时管理系统是一个面向片场租赁场景的计时计费解决方案，支持会员管理、场地预约、实时计时、增值服务和在线结算。

## 功能特性

- 会员注册与登录
- 场地选择与预约
- 实时计时
- 增值服务点单
- 在线充值与结算
- 管理员后台

## 技术栈

- Next.js 14
- TypeScript
- Prisma
- SQLite (本地) / MySQL (生产)

## 开发

```bash
# 安装依赖
npm install

# 运行开发服务器
npm run dev

# 构建生产版本
npm run build
```
